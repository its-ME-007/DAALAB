C++ Tips

  • Always include necessary headers (iostream, vector, etc.)
  • Use std::cout for output
  • Code is compiled with GCC and C++17 standard
  • Execution time is measured and displayed
  • Make sure your code has a main() function

C++ Example Code

#include <iostream>
#include <vector>

int main() {
    // Simple calculation
    int x = 10, y = 20;
    std::cout << "Sum: " << x + y << std::endl;
    
    // Vector operations
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    int sum = 0;
    for (int num : numbers) {
        sum += num;
    }
    std::cout << "Sum of vector: " << sum << std::endl;
    
    return 0;
}
